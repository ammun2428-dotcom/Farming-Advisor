# 🌾 Farming Advisor Pro

A weather-based smart farming advisory system that provides real-time weather information and crop recommendations using the OpenWeather API and GPS-based location services.

## 📖 Overview

Farming Advisor Pro helps farmers and agriculture enthusiasts make informed decisions by analyzing current weather conditions and suggesting suitable crops for cultivation.

The application fetches live weather data, detects user location through GPS, and dynamically updates the interface based on environmental conditions.

---

## ✨ Features

- 🌦️ Real-time weather updates
- 📍 GPS-based location detection
- 🌱 Smart crop recommendations
- 🌡️ Temperature monitoring
- 💧 Humidity analysis
- 🎨 Dynamic weather-themed UI
- ☁️ Animated clouds and weather effects
- 🌧️ Rain visualization
- 📱 Fully responsive design

## 🚀 How It Works

1. Enter a city name or use the Live GPS feature.
2. The application fetches weather data from OpenWeather API.
3. Weather parameters such as temperature, humidity, and conditions are analyzed.
4. Suitable crop recommendations are displayed.
5. The visual environment adapts to the current weather.

---

## 🌱 Crop Recommendation Logic

| Weather Condition | Recommended Crops |
|------------------|------------------|
| Rainy Weather | Rice, Sugarcane |
| Hot & Dry | Millets, Groundnut |
| Hot & Humid | Sorghum, Cotton |
| Moderate Climate | Rice, Maize, Vegetables |
| Cold Climate | Wheat, Barley |
